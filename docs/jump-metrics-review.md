# 单跳资格器独立审查

2026-10-27，训练前审查。对象为新增 `examples/jump_metrics.py`；原落地冻结源码未修改。本审查只确认测量及事件判定逻辑，不代表机器人已经通过单跳物理验收。

## 审查发现与修复

初版用“历史上出现过双轮支撑”证明主动地面起跳，可被以下合成轨迹误接受：先站稳，0.8秒开始完全失支撑但轮隙仍小于2毫米，1.1秒才进入大于2毫米的净空段。它把净空越阈时刻误当作地面离地时刻。

已修复为从合格净空段向前追溯连续“双轮均无有效支撑”的区间起点，用实际失去最后一轮有效支撑的时刻检查1–3秒起跳窗口。区间前必须紧接有效地面支撑，且此前双轮支撑到最后单轮离地的过渡不得超过20毫秒；20毫秒接受，22毫秒拒绝。因此历史站稳不再独自证明当次地面起跳。净空段开始时刻另外保存为 `clearance_start_s`。

## 当前验收定义

- 每个2毫秒物理子步先刷新派生状态再测量，共10000个有效时间区间，运行至20秒；允许另有t=0初始行，禁止缺样或时间错序。
- 1秒前连续至少0.5秒双轮各法向力>1牛顿，upright>=0.95、世界水平速度<=0.15米/秒、陀螺模长<=1弧度/秒。
- 恰好一次双轮各无>1牛顿有效支撑、双轮圆柱碰撞几何净空均>2毫米持续至少60毫秒的事件。
- 实际失去最后一轮有效支撑的起跳时刻位于1–3秒；紧邻的单轮过渡<=20毫秒。此次失支撑至合格净空段结束期间，整机质心世界竖直速度峰值>0.15米/秒。
- 合格净空段中，两轮较低净空的峰值为1.5–3厘米；全程两轮较低净空不得超过3厘米。
- 腾空后双轮各>1牛顿连续至少50毫秒确认着地。自该着地区间起，任何双轮支撑条件失效不得连续超过20毫秒，包括只剩单轮的情况。
- 全程upright不得低于0.5；非轮地面法向力合计不得>1牛顿。非轮合计门槛比逐接触门槛保守。
- 全程水平位移相对初始位置<=0.2米；最后5秒水平包围盒对角线<=0.05米；结束前连续至少3秒符合完整稳定条件，终点失稳会清零稳定时间。

接触、几何、质心均为评估真值，不是actor输入。`mj_subtreeVel` 显式刷新整机子树速度，并检查浮基子树质量等于机器人总质量；轮底由碰撞圆柱半径、半宽与世界朝向计算。调用者须在每个子步先 `mj_forward`，避免积分后时间配上积分前派生状态。

## 资格边界

主动性结论还依赖环境不重置状态、不施加外力/外加冲量、不移动地面，以及执行中的实际电机约束。测量器本身不能从任意伪造的JSON证明因果；最终需联合环境源码、实际动作与完整轨迹审查。17牛米及力矩速度约束由原物理控制层执行，应在最终独立审查中另核实实际力矩记录。500Hz采样不证明排除了任意更短的接触事件。允许的20毫秒着地后失支撑是明确容差，不等价于绝对持续双轮接触。

最终必须冻结资格源码与模型后，一次执行30个预定独立种子、每回合完整20秒，全部通过并保留轨迹和实际视频；本报告不能替代该阶段。
