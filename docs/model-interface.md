# 模型与策略契约（v0.2）

## 来源与物理范围

两份原始资料固定于包内 [upstream.lock.json](../diablo_training/upstream.lock.json)：

- [厂家推荐RL资源](https://github.com/DDTRobot/Col_DIABLO_Issac_RL/tree/590085a027fc9e20b1d7e976714cd195488b96b6)：使用 `diablo.urdf` 的几何、质量、惯量，以及 `diablo_asm.urdf` 的回程连杆惯量/网格。
- [官方Webots机构](https://github.com/DDTRobot/diablo-sim-env/blob/3c9abbcaeb93911932b9c14777c4e75cc8c1470e/diablo_A1/protos/DiabloOriginal.proto)：串联电机的连接、轴向、连杆端点、回程支链及闭环关系。
- [DIABLO论文](https://arxiv.org/html/2407.21500v1)：III-A描述串联髋膝电机和承力平行四边形；表I/II提供机构与电机参考数据。

MuJoCo适配在内存里生成模型，原文件不改写。每侧三个主动电机，加两个被动铰链、一个闭环连接约束；全机6个执行器、4个被动关节、2个闭环，浮动基座后 `nq=17,nv=16,nu=6,neq=2`。保留被动连杆质量，不能把等效串联关节直接当成实机电机。

| 参数 | 本仿真 | 边界 |
|---|---|---|
| 总质量 | 21.019506 kg | CAD质量加两根回程连杆；论文22.90 kg，未称量或强行配平 |
| 主轮碰撞半径 | 0.1 m | 保留CAD圆柱；论文0.0935 m，两者版本差异未标定 |
| 主连杆长度 | 0.14 m | 官方几何 |
| 平行支链基距 | 0.09 m | 官方几何 |
| 力矩/转速参考 | 堵转17 Nm、空载220 rpm（23.03835 rad/s） | 论文M1502D；额定9.6 Nm，未建热模型、驱动器限流和延迟 |
| 包络 | 同向随转速线性降力矩，反向制动力矩限17 Nm | 建模假设，不是实机驱动曲线 |
| 摩擦 | `[0.8,0.005,0.0001]` | MuJoCo滑动、扭转、滚动参数；未标定 |

关闭机器人自碰撞，保留身体/腿/轮与地面碰撞。底部四个爬行小滚轮未独立建模；本环境不用于爬行训练。默认地面是平面，未提供越野、跳跃或高度图课程。改变这些物理假设后需重新验证和训练。

## 电机、零位和动作

动作顺序按名称绑定，**不会假定URDF导入顺序**：

| 索引 | MuJoCo电机名 | 官方Webots名 | 原始q/dq轴 | 策略正向 |
|---|---|---|---|---|
| 0 | left_hip_motor | left_j4 | 电机局部-z | 原始角度增加 |
| 1 | left_knee_motor | left_j1 | 电机局部-z | 原始角度增加 |
| 2 | left_wheel_motor | left_j3 | 电机局部-z | 原始角度减少，轮沿机体+x滚动 |
| 3 | right_hip_motor | right_j4 | 电机局部-z | 原始角度增加 |
| 4 | right_knee_motor | right_j1 | 电机局部-z | 原始角度增加 |
| 5 | right_wheel_motor | right_j3 | 电机局部-z | 原始角度减少，轮沿机体+x滚动 |

CAD电机零位保留。默认原始 `q=[0.5,-1,0,0.5,-1,0] rad`。每侧被动回程铰链 `q_return=q_knee`、支链铰链 `q_branch=-q_knee` 初始化在同一闭环分支。仿真后由约束求解器推进，不能每帧强行改写被动关节以消除误差。

输出是6维归一化动作，float32，限幅到 `[-1,1]`。支持两种明确语义，训练时选定并随检查点保存：

**默认 `position_velocity`：**腿部 `tau=kp*(q_default+0.5*a-q)-kd*dq+tau_ff`，两侧髋/膝kp=15/18，kd=0.3/0.2；轮部 `tau_raw=0.3*(-10*a-dq_raw)`。动作不是Nm，也不是轮位置。支撑前馈每腿60 N，`tau_ff,knee=60*0.14*sin((-2.8729-q_knee)/2)`，髋/轮前馈为0。它由实际电机坐标的腿长Jacobian推导，不套用等效串联关节公式。

**`torque`：** `tau_raw=17*a*[1,1,-1,1,1,-1]`，不加入PD或支撑前馈。两种模式均经过转速包络和MuJoCo执行器±17 Nm限制。

最终策略输出不包含控制器；ONNX/TorchScript输出仍是归一化动作。执行仿真时还必须使用相同控制映射和时钟。

## 观测、坐标、时钟

世界z向上；沿用原始基座机体系，x为前进。m、rad、rad/s、Nm、s。物理步长2 ms，控制周期10 ms，动作保持五个子步。奖励和评估线速度在**基座坐标系**计算，不能误用MuJoCo惯性主轴系。

每帧25维，float32：

| 切片 | 内容 | 缩放 |
|---|---|---|
| `0:3` | 机体IMU陀螺仪 | ×0.25 |
| `3:6` | 估计的机体系单位重力向量 | ×1 |
| `6:9` | 当前前进m/s、偏航rad/s、机身高度m指令 | ×[10,0.25,5] |
| `9:13` | 左髋、左膝、右髋、右膝相对默认原始角度 | ×1 |
| `13:19` | 六电机速度，轮速度反号以正向前进 | ×0.05 |
| `19:25` | 上一步限幅后的归一化动作 | ×1 |

五帧按最旧→最新拼接，**包含当前帧**，得到 `[125]`。reset时复制初始帧五份，上一步动作清零。每控制步只更新一次历史。动作a(t)作用于o(t)，奖励使用o(t)对应的指令；新观测携带t+10 ms的新指令以及a(t)。不得提前用下一阶段指令计算当前奖励。

陀螺仪、加速度来自site传感器。重力方向由陀螺积分、在加速度模长接近重力时融合修正得到；初始已知水平姿态。策略不读取真值基座姿态、真值线速度或真值位置。训练奖励、终止和评估允许使用物理真值；这是训练监督，不能搬入实机策略输入。可选噪声只涉及陀螺和编码器速度，不是完整sim2real随机化。

## 校核与失败

`diablo doctor` 同时执行Gymnasium接口检查和独立机构检查：

- 从锁定Webots文件独立读取髋轴、锚点、初始姿态，组合官方连杆变换；12组姿态、左右轮轴位置对比MuJoCo。
- 闭环几何、质量和正惯量、六电机名称绑定；实际编译模型中单位力矩加速度与广义力、功率一致性。
- 独立有限差分腿长，验证径向力→电机力矩的虚功关系；正轮动作的无滑滚动方向。
- 单位驱动检查临时隔离重力/地面影响，不是原地站立能力测试。

`tests/`另检查已知线速度与旋转后的机体系、指令/历史时序、限幅、复位和检查点不兼容拒绝。运行中闭环残差超过5 mm、非有限状态或MuJoCo数值警告立即抛错；禁用MuJoCo自动数值复位。数值故障后必须重建环境，不自动恢复运动。训练保存失败证据后退出。

正常跌倒或时间上限属于RL回合终止，允许训练采样复位。评估每个任务只计首回合，不自动重试。身体触地或机体上方向与世界z点积低于0.5时终止；这些默认失败定义可在任务扩展时明确修改。

## 保存和导出兼容性

`resolved.json`保存环境、任务类、PPO设置、上游提交、软件版本和契约指纹。指纹覆盖模型/控制/环境实现、任务类所在模块源码、动作模式、MuJoCo版本和来源信息；**输入输出维度相同也不能跳过校验**。指纹同时写入SB3检查点，防止将旧权重与新配置配对。续训、评估和导出均检查指纹。保守校验也会拒绝这些实现文件的无行为源码修改；使用原提交重现，或开始新实验。自定义类依赖的外部辅助文件仍需自行版本管理。

v0.1的18.041006 kg等效模型、旧电机坐标和速度轴错误已经被本版替换，**旧检查点不兼容，不能迁移为本版策略**。原始失败日志仍保留，不改成新版结果。

ONNX opset17和TorchScript：输入名 `observation`，float32 `[N,125]`；输出名 `action`，float32 `[N,6]`，无隐状态输入。导出实际对比原SB3策略，容差 `atol=rtol=1e-5`。此接口不是官方Isaac历史编码策略接口，也不是D1h或DIABLO SDK的实机通用接口。始终 `simulation_only=true, hardware_authorized=false`。
