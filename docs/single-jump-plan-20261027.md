# 平地单次原地小跳计划

## 步骤与审查门槛
1. 核验提交、资产、运行时、真实CUDA运算和旧证据；不改旧冻结代码，不覆盖已有工作区修改。
2. 独立环境从轮地间隙0、零初速复位，先站立1秒，再发出单次蹬地指令。开发搜索仅用于可行性，不是最终资格。
3. 在PPO训练前冻结独立资格器和物理事件契约，检查环境API及反例：无指令、仅抬机身、初始释放均不得通过。
4. 保留LQR传感反馈，训练新的PPO有界残差；保存种子、配置、参数变化、模型和契约。按物理结果迭代，不以奖励决定完成。
5. 冻结候选后，30个独立种子，每回合20秒，保存完整子步轨迹与真实视频；独立审查从轨迹重算，禁止重试挑选成功样本。

## 预定验收定义（最终冻结前可审查修订）
- 物理子步500Hz采样（以实际PHYSICS_DT核对）；轮底按碰撞圆柱几何和世界朝向计算；不使用机身抬高代替轮底离地。
- 1秒前，至少连续0.5秒双轮各法向力>1N，upright>=0.95，水平速度<=0.15m/s、陀螺模长<=1rad/s；起跳前已站稳。
- 起跳窗1–3秒，双轮均无有效支持，轮底均高于2mm持续至少60ms；离地上升阶段全机COM世界竖直速度>0.15m/s，排除收腿假跳；两轮最小间隙峰值1.5–3cm（目标2cm）。必须先有地面有效支持再主动上升。
- 着地事件为腾空后双轮恢复有效支持至少50ms；只允许一次合格腾空。着地后不再次失去双轮支撑超过20ms。
- 每回合完整20秒，无摔倒、无任何非轮法向支撑>1N；全程水平漂移<=0.2m，末5秒水平包围盒对角线<=0.05m。
- 末段连续至少3秒双轮各>1N、upright>=0.95、水平速度<=0.15m/s、陀螺模长<=1rad/s；保持至结束。
- 保留17Nm及原力矩速度约束。真值仅用于奖励和独立评估，控制/actor仅IMU、编码器、时钟。声明范围限于已知直立、无偏陀螺、平地仿真单跳。
